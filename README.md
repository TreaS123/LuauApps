# Weather Director — HiddenDevs Application Demo

Single LocalScript weather system for Luau Scripter application.

**Credits:** Discord `treas123` · Roblox `TreaS271`

## Setup

1. Open the place in Roblox Studio (Rojo sync or paste `WeatherDirector.client.luau` into StarterPlayerScripts).
2. Publish the place and set the game description to credit treas123 / TreaS271.
3. Submit **only the Roblox place link** — one link, no extra text.

## Features

- State machine (Clear, Rain, Storm, Fog) via metatables
- Rain particles, wind physics, raycast lightning
- Built-in UI panel and demo wind props
