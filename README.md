## Demo

1. `rojo build -o "weather-demo.rbxlx"` or `rojo serve` and connect in Studio
2. Play — bottom-left panel: weather buttons + time presets
3. Storm shows rain, wind on tagged loose parts, lightning flashes
4. Tag your own parts with `WindAffected` (CollectionService) to push them in rain/storm/fog

## Getting started

```bash
rojo build -o "weather-demo.rbxlx"
```

```bash
rojo serve
```
